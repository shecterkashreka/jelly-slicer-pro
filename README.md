# Jelly Slicer Pro — 3D ASMR Physics Game 🍮✨

> Красочная 3D физическая игра с нарезкой желе, реалистичной упругой физикой (тряска, сплющивание, сохранение объёма), сочными эффектами всплесков сиропа и глубоким процедурным ASMR-звуком.

---

## 🎮 Возможности
- **Честная 3D-нарезка геометрии:** нарезка любых фигур под произвольным углом плоскостью в реальном времени с автоматической запайкой срезов и расчётом нормалей.
- **Мягкое желе и упругая физика (Squash & Wobble):** кастомный шейдер деформации Three.js сохраняет объём при падениях и ударах.
- **Устойчивая опора и честные коллизии кусков:** желе и отрезанные дольки ложатся на разделочную доску без укатывания и не проходят друг сквозь друга благодаря повершинной проверке контакта.
- **6 разнообразных форм желе:** снежинка, мишка, сердце, груша, пончик (торус), звезда.
- **Сочные цвета и сироп:** палитра из 7 насыщенных желеобразных оттенков с брызгами сиропа при каждом успешном срезе.
- **Синтезированный Web Audio ASMR-звук:** процедурный низкочастотный глухой звук разреза, отскоки и звуки спавна без внешних аудиофайлов.
- **100% Автономность:** все библиотеки (`Three.js`, `Cannon-es`, `OrbitControls`) зашиты локально, игра запускается мгновенно даже без подключения к интернету.

## 🕹️ Управление

| Клавиша / Действие | Функция |
|---|---|
| **ЛКМ (зажать и провести)** | Разрезать желе по линии лазера |
| **Пробел** | Заспавнить случайное желе со случайным цветом |
| **T** | Переключить режим замедления времени (Слоу-Мо) |
| **R** | Очистить разделочную доску |
| **F11** | Переключить полноэкранный режим |
| **ПКМ / СКМ** | Вращать камеру вокруг стола |
| **Колёсико мыши** | Приближение / отдаление (зум) |

## 🚀 Как запустить

### Вариант 1: Запуск готового `.exe` (самый простой)
Просто скачайте и запустите `JellySlicerPro.exe`.
- Установка Python или сторонних библиотек **не требуется**.
- Работает полностью оффлайн на любой современной Windows.

### Вариант 2: Запуск из исходного кода через Python
1. Убедитесь, что установлен Python 3.10+:
   ```bash
   python --version
   ```
2. Запустите лаунчер:
   ```bash
   python main.py
   ```
   (или дважды кликните по `run.bat`).
3. Игра откроется в компактном изолированном окне приложения.

### Вариант 3: Запуск в любом веб-браузере
Поднимите любой локальный HTTP-сервер в папке проекта:
```bash
python -m http.server 8000
```
И откройте в браузере `http://localhost:8000/index.html`.

## 🛠️ Стек технологий
- **Three.js (WebGL)** — 3D-рендер, шейдеры полупрозрачности, SSS, спекулярные блики, динамические тени.
- **Cannon-es** — физический движок твёрдых тел, расчёт импульсов, трения и гравитации.
- **Web Audio API** — процедурный синтез звуков нарезки, спавна и отскоков.
- **Python / PyWebView / Chromium App** — компактная настольная оболочка для Windows.
